How do I measure this?
{% if s.key == 'ph' %}

Use a pH strip or liquid tester. Dip it for the time on the pack, match the colour, and type the number. Test the water cool and still, straight from the tap.

{% endif %} {% if s.key == 'turbidity' %}

Fill a clear glass or use your turbidity tube. Compare with the chart in your kit, or judge it: clear = under 1 NTU, milky = 5 NTU or more.

{% endif %} {% if s.key == 'tds' %}

Switch on the TDS meter, dip it in the sample, wait for the reading to settle and type the mg/L number. Do not use it in very hot water.

{% endif %} {% if s.key == 'dissolved_oxygen' %}

Use a DO probe or a chemical test kit. Let the sample sit still, wait for the number to stabilise, then type the mg/L value.

{% endif %}

Rinse the container with the sample water first, and test near the time you collected the water.
